🧮 BMI Calculator App

A simple and interactive Body Mass Index (BMI) Calculator App built using Flutter.
This app helps users calculate their BMI based on height and weight, and displays whether they are underweight, normal, overweight, or obese — with a clean UI and instant results.

🚀 Features

🧠 Instant BMI Calculation
Enter your height and weight to get your BMI instantly.

🎨 Clean & Modern UI
Built with Flutter’s Material Design for a smooth and responsive experience.

📊 Health Category Display
Shows BMI category (Underweight, Normal, Overweight, Obese).

💾 Lightweight and Fast
Optimized for performance with minimal resource usage.

🔁 Reset Functionality
Easily clear input fields to calculate again.

🛠️ Tech Stack

Framework: Flutter

Language: Dart

IDE: VS Code / Android Studio

Platform: Android (can be extended to iOS, Web)
